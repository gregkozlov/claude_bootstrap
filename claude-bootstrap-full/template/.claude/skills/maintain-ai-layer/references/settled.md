# Settled findings for maintain-ai-layer

Findings an earlier run raised and the owner decided, or the run rejected with a reason the owner accepted. Paste this list into every agent prompt. A new finding that matches an entry is logged as `settled (settled.md)` and never reported again - unless it brings evidence the entry did not have, in which case it is reported as reopening that entry.

An entry is a finding, not a fact about the code: when the code it describes changes, the entry stops applying and the finding is judged fresh. Add an entry at the end of each run for every owner answer and every rejection the owner did not overturn.
